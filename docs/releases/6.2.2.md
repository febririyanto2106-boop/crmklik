# WACRM 6.2.2 release notes

Released: 2026-10-13

Version 6.2.2 improves inbox and contact reliability, campaign and drip workflows, integration persistence, billing workspace isolation and production startup.

## Inbox and contact reliability

- Resolve Messenger recipient names and search imported contacts correctly; refresh inbox messages after separate-page sends and on polling or focus.
- Clear incompatible conversation selections when changing channels or accounts, continue pagination through undated conversations, and preserve scalar contact names, phone numbers and email addresses during edits.

## Campaigns and drip sequences

- Keep campaign dialog actions accessible, surface upload and queue-stat errors, refresh private media URLs at delivery, and show stalled-queue diagnostics.
- Add editable drip steps, checked activation, manual enrollment and future-contact welcome enrollment. Stage dispatch and enrollment updates transactionally with recipient eligibility checks and replay protection.

## Integrations and OAuth

- Use the canonical application origin and reuse exact signed callback URLs for social OAuth authorization and token exchange.
- Add Google Workspace gateway administration, encrypted server-side credential persistence, workspace-scoped account restoration and checked connection actions. Scope installed integration metadata by user and workspace.

## Billing integrity and workspace isolation

- Save invoice and quote headers and lines atomically, preserving original content when validation or insertion fails.
- Reject cross-workspace payment, document-line and product references at the database boundary. Recalculate both documents when moving payments or lines, restore payment states correctly and preserve shared deal totals.

## Startup and compatibility

- Stop the retired service-worker registration and reload loop while preserving unrelated workers and caches. Render the root error page without requiring the failed root query provider.
- Correct the animation-module import, conversation account typing and integration dialog HTML semantics.

## Upgrade and verification

- Apply both 20261012 migrations with the matching application build. Existing historical billing workspace mismatches require separate review; these guards do not automatically repair old records.
- Local verification passed 811 regression tests, 79 PostgreSQL checks, the full typecheck, the production build and four public browser smoke checks. Live OAuth, provider ingestion, campaign delivery and authenticated staging checks remain required.
- Automatic drip enrollment currently covers future-contact welcome journeys; birthday, anniversary, no-reply and stalled-lead event integrations remain separate work.
